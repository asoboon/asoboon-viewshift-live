# VIEWSHIFT · ASOBooN staff-perspective game

Official standalone playable static build of the original VIEWSHIFT pixel RPG.

- 8 fictionalized MBTI-informed protagonists, 57 scenes, 14 choices per week
- 12 revised incidents × 8 original character inner monologues
- 288 character-specific action options, 5 original animated event clips
- At week end, try the same 14 incidents as another protagonist

All characters, monologues and choices are game fiction, not assertions of real staff psychology.

Built from asoboon/asoboon-viewshift-real source revision 987e5ea; hosted via GitHub Pages.
